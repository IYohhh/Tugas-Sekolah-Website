## 🏫 Tentang Project

Website SMA Pelita Harapan merupakan website profil sekolah yang digunakan sebagai media penyampaian informasi sekolah secara digital.

Website ini menyediakan berbagai informasi seperti:

* Profil sekolah
* Program pendidikan
* Kegiatan siswa
* Informasi PPDB
* Galeri kegiatan
* Informasi kontak sekolah

Website dibuat agar informasi sekolah dapat disampaikan secara lebih menarik, terstruktur, dan mudah digunakan.

---

## 🎯 Tujuan Project

Tujuan dari pembuatan website ini adalah:

1. Menyediakan informasi sekolah secara digital.
2. Memperkenalkan program dan kegiatan sekolah.
3. Memberikan informasi PPDB kepada calon siswa.
4. Menampilkan dokumentasi kegiatan sekolah.
5. Memudahkan pengguna menemukan informasi kontak sekolah.
6. Membuat media informasi sekolah yang modern dan mudah digunakan.

---

# 📥 Cara Mendapatkan Project

## 1. Clone Repository

Buka terminal atau Git Bash, kemudian jalankan:

```bash
git clone https://github.com/username/Tugas-Sekolah-Website.git
```

Masuk ke folder project:

```bash
cd Tugas-Sekolah-Website
```

> Ganti URL repository sesuai repository GitHub yang digunakan.

## 2. Download Repository

Cara lainnya adalah:

1. Buka repository GitHub.
2. Klik tombol **Code**.
3. Pilih **Download ZIP**.
4. Extract file ZIP.
5. Buka folder project menggunakan Visual Studio Code.

# ▶️ Cara Menjalankan Website

## Menggunakan Visual Studio Code + Live Server

### Langkah 1

Buka **Visual Studio Code**.

### Langkah 2

Pilih:

```text

```



```text

```

Kemudian pilih:

```text

```

Website akan terbuka di browser.

Contoh alamat:

```text
http://127.0.0.1:5500/
```

# ✏️ Tata Cara Mengubah Isi Website

Untuk mengubah teks pada website:

## 1. Buka file HTML

Contohnya:

```text
index.html
```

## 2. Cari teks yang ingin diubah

Contoh:

```html
<h1>Sekolah yang menginspirasi generasi masa depan</h1>
```

## 3. Ganti teks

Contoh:

```html
<h1>Sekolah yang Mempersiapkan Masa Depan</h1>
```

## 4. Simpan

Tekan:

```text
Ctrl + S
```

Kemudian refresh browser.

# 🖼️ Tata Cara Mengganti Gambar

## 1. Siapkan gambar

Format yang disarankan:

```text
.jpg
.jpeg
.png
.webp
```

## 2. Masukkan gambar ke folder

Contoh:

```text
img/
├── hero.jpg
├── kegiatan-1.jpg
└── kegiatan-2.jpg
```

## 3. Hubungkan gambar ke HTML

Contoh:

```html
<img src="img/hero.jpg" alt="Kegiatan siswa">
```

Untuk mengganti gambar:

```html
<img src="img/hero-baru.jpg" alt="Kegiatan siswa">
```

## ⚠️ Perhatikan Nama File

Penulisan nama file harus sama.

```text
hero.jpg
```

berbeda dengan:

```text
Hero.jpg
```

# 🔧 Troubleshooting

## Gambar Tidak Muncul

Periksa:

* Lokasi folder gambar
* Nama file
* Ekstensi file
* Penulisan path

Contoh:

```html
<img src="img/hero.jpg" alt="Hero">
```

---

## CSS Tidak Berubah

Pastikan CSS sudah terhubung:

```html
<link rel="stylesheet" href="css/style.css">
```

Kemudian lakukan refresh menggunakan:

```text
Ctrl + Shift + R
```

---

## JavaScript Tidak Berjalan

Pastikan file JS sudah terhubung:

```html
<script src="js/script.js"></script>
```

Kemudian periksa tab Console pada browser:

```text
F12 → Console
```

---

## Menu Tidak Bisa Diklik

Periksa atribut `href`.

Contoh:

```html
<a href="pages/tentang.html">Tentang</a>
```

Pastikan file `tentang.html` memang berada di folder `pages`.
